## Global Rules

### Color Palette (zinc neutrals + one accent — never mix warm/cool greys)

| Role | Dark | Light | CSS Variable |
|---|---|---|---|
| Background | `#09090B` | `#FAFAFA` | `--color-bg` |
| Surface | `#111114` | `#FFFFFF` | `--color-surface` |
| Elevated | `#18181B` | `#F4F4F5` | `--color-elevated` |
| Border | `rgba(255,255,255,0.08)` | `rgba(0,0,0,0.08)` | `--color-border` |
| Text | `#EDEDEF` | `#18181B` | `--color-text` |
| Muted text | `#8A8F98` | `#52525B` | `--color-muted` |
| Accent — "grounded" (verified) | `#45C98F` | `#1B7A51` | `--color-grounded` |
| Status — "flagged" (unverified) | `#E0A84F` | `#A86A12` | `--color-flagged` |
| Destructive | `#EF4444` | `#DC2626` | `--color-destructive` |

Single accent only (grounded green). Amber is a functional status colour
(flagged numbers), never a second brand accent. Never pure black (`#000000`)
— background is `#09090B` (zinc-950-adjacent). Status is never colour-only:
grounded pairs with a check icon, flagged with a warning icon. Verify every
text/background pair ≥4.5:1 and every chart mark ≥3:1, independently in both
themes (per `ui-ux-pro-max`'s own checklist — don't infer one theme from the
other).

### Typography

- **Display** (H1–H3): Cabinet Grotesk, 700–800, `tracking-tighter`,
  `leading-none`. Scale `text-4xl md:text-6xl`. The H1 must not scream —
  control hierarchy with weight/colour, not size alone.
- **Body/UI**: Satoshi, 400/500, 16px min, `leading-relaxed`, `max-w-[65ch]`.
- **Data** (every number on the site, no exceptions): JetBrains Mono,
  `font-variant-numeric: tabular-nums`.
- Self-host all three via `next/font/local`, `display: swap`. Both from
  Fontshare (Cabinet Grotesk, Satoshi) + Google Fonts (JetBrains Mono).
- No Inter, anywhere, for any purpose.

### Spacing (4/8px rhythm)

| Token | Value |
|---|---|
| `--space-xs` | 4px |
| `--space-sm` | 8px |
| `--space-md` | 16px |
| `--space-lg` | 24px |
| `--space-xl` | 32px |
| `--space-2xl` | 48px |
| `--space-3xl` | 64px |

### Shadows — tinted diffusion, never a raw drop shadow

| Level | Value | Usage |
|---|---|---|
| `--shadow-card` | `0 20px 40px -15px rgba(0,0,0,0.05)` (light) / `rgba(0,0,0,0.4)` (dark) | Cards where elevation means something |
| `--shadow-inner-highlight` | `inset 0 1px 0 rgba(255,255,255,0.06)` | Card top edge, glass panels |

No `box-shadow` glows, no neon outer glow, no gradient text.

### Motion tokens

- Spring: `stiffness: 100, damping: 20` (Framer/`motion` default for this site)
- Easing (CSS transitions): `cubic-bezier(0.16, 1, 0.3, 1)`
- Micro-interactions: 150–300ms · section reveals: ≤400ms · exits: ~65% of
  enter duration · list stagger: 40ms/item
- Animate `transform`/`opacity` only, ever
- `prefers-reduced-motion`: every animation resolves instantly to final state

## Component Specs

### Buttons

```css
.btn-primary {
  background: var(--color-grounded);
  color: var(--color-bg);
  padding: 12px 24px;
  border-radius: 12px; /* rounded-xl, not the tool's rounded-lg default */
  font-weight: 600;
  transition: transform 200ms cubic-bezier(0.16,1,0.3,1), opacity 200ms;
  cursor: pointer;
}
.btn-primary:active { transform: translateY(1px) scale(0.98); }

.btn-secondary {
  background: transparent;
  color: var(--color-text);
  border: 1px solid var(--color-border);
  padding: 12px 24px;
  border-radius: 12px;
  font-weight: 600;
}
```

### Cards

```css
.card {
  background: var(--color-surface);
  border: 1px solid var(--color-border);
  border-radius: 24px; /* rounded-2xl */
  padding: 32px; /* p-8, generous */
  box-shadow: var(--shadow-card), var(--shadow-inner-highlight);
}
```
Use cards only where elevation communicates hierarchy — density sections
(the incident log, the metrics band) use `divide-y`/hairline borders instead
of boxing everything, per taste-skill's anti-card-overuse rule.

### Inputs (verifier demo's editable number field)

```css
.input {
  padding: 8px 12px;
  border: 1px solid var(--color-border);
  border-radius: 8px;
  font: inherit;
  font-family: 'JetBrains Mono', monospace; /* numeric inputs are mono */
  transition: border-color 200ms;
}
.input:focus {
  border-color: var(--color-grounded);
  outline: none;
  box-shadow: 0 0 0 3px color-mix(in srgb, var(--color-grounded) 20%, transparent);
}
```

## Style Guidelines

**Style:** "The Audited Terminal" — editorial precision meets developer
terminal. Light + dark, dark default. Ledger-grid texture (1px lines, ~4%
opacity) behind hero/metrics, radial-masked. Film grain on one fixed
`pointer-events-none` overlay only, never on scrolling containers. One slow
ambient accent blob behind the hero at 6–8% opacity.

**Icons:** `@phosphor-icons/react` exclusively (not Heroicons/Lucide — check
`package.json` before install, per taste-skill's dependency-verification
rule). One stroke weight (1.5 or 2.0) across the whole site.

### Page Pattern

Not the generic "Hero > Features > CTA" 3-section minimal pattern — this is
a 14-section long-form landing+dashboard page. See
`docs/superpowers/specs/2026-09-28-public-website-design.md` §Sections for
the full order (nav → hero → metrics → problem → how-it-works → verifier →
tools bento → measured-not-claimed charts → incident log → cost/latency →
stack grid → deploy-your-own → closing CTA/footer).

---

## Anti-Patterns (Do NOT Use)

- ❌ Dark-only (this project needs a light/dark toggle — the tool's Dark
  Mode (OLED) style default is overridden)
- ❌ JetBrains Mono for headings/body (mono is numbers-only here)
- ❌ Text-shadow glow effects (banned by taste-skill)
- ❌ Purple/blue "AI" gradient glows, neon button glows
- ❌ Pure black backgrounds
- ❌ Centered hero (split layout per the settled decision)
- ❌ 3-equal-card feature rows (use 2fr/1fr asymmetric or zig-zag)
- ❌ Emojis as icons — Phosphor only
- ❌ Missing `cursor-pointer` on clickable elements
- ❌ Layout-shifting hovers (animate transform/opacity only)
- ❌ Instant state changes — always 150–300ms transitions
- ❌ Invisible focus states
- ❌ Hard-coded numbers in the UI outside `<Cited>`/`metrics.json`

## Pre-Delivery Checklist

- [ ] No emojis used as icons (Phosphor only)
- [ ] `cursor-pointer` on all clickable elements
- [ ] Hover/focus states with smooth transitions (150–300ms)
- [ ] Both themes independently checked at 4.5:1 text contrast, 3:1 chart marks
- [ ] Focus states visible for keyboard navigation, incl. `<Cited>` on focus
- [ ] `prefers-reduced-motion` respected — instant final state, content readable
- [ ] Responsive: 375px, 768px, 1024px, 1440px, no horizontal scroll
- [ ] No content hidden behind the sticky nav
- [ ] Every number on the page resolves through `data/metrics.json`
